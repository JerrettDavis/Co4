# Working name and domain workshop

Research snapshot: **2026-09-24**. Availability was checked with the connected Namecheap domain availability/pricing tool. These are point-in-time results, not registrations, renewals, tax-inclusive quotes, or trademark clearance.

## Recommendation: Co4

Four Co-words: Code, Collaboration, Cooperation, Computation. Use **Co4** in the UI, `co4` as the CLI/repository, and **Co4Code** where a more searchable expanded name is needed. It is short enough to say in an issue comment and does not suggest that the platform replaces a coding harness. The website candidate is **co4code.com**, returned available at USD 11.28 for the displayed purchase price.

The main drawback is ambiguity: Co4 is not self-explanatory in search and the shortest matching developer domains were unavailable. Pair it with the descriptor “cooperative development orchestration” rather than relying on the name alone. This research did not constitute an exhaustive search for existing Co4 marks, packages, or businesses.

No domain was purchased. A free domain does not establish that a mark, organization name, CLI name, package name, or social handle is free. Run appropriate legal and marketplace clearance before a public launch. The playful `CoCoCode.op` example was treated as inspiration, not an assertion that `.op` was available or registrable.

Primary collision checks included [CoCompute](https://cocompute.ai/), [CoCrew](https://cocrew.ai/), [CoCommit](https://github.com/andrewromanenco/cocommit), and [CodeCoop](https://github.com/BartoszMilewski/CodeCoop). A broader web search also surfaced CocoDev in a game/developer context. Recheck both domains and usage at launch.
